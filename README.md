# GlassChat — Liquid Glass Tinted

Мобильный веб-мессенджер/PWA с настоящей регистрацией и перепиской между аккаунтами. Работает с телефона; компьютер не обязателен.

## Что уже реализовано
- Регистрация и вход по email/паролю через Supabase Auth.
- Поиск пользователя по точному email.
- Создание личных чатов.
- Сохранение сообщений в PostgreSQL и обновления через Supabase Realtime.
- RLS-политики для чтения чатов только участниками и отправки сообщений только от своего аккаунта.
- Адаптивный интерфейс с Liquid Glass-подобным tint, blur, бликами и сменой цветового оттенка.
- PWA-заготовка.

## Важно
Это стартовая версия, не production-ready: нет групповых чатов, отправки файлов/голосовых, push-уведомлений, блокировки пользователей, жалоб, восстановления пароля и защиты от спама. Для публичного запуска добавь rate limits/anti-abuse, политику конфиденциальности и правила использования. Не публикуй service_role key — в клиентском коде допустим только anon/publishable key при включённом RLS.

## Настройка с Android, без ПК

### 1. Создай backend в Supabase
1. Открой https://supabase.com/ в браузере и создай проект.
2. В проекте открой **SQL Editor → New query**.
3. Скопируй весь файл `supabase.sql`, вставь и нажми **Run**.
4. Открой **Project Settings → API** (или Connect) и скопируй Project URL и anon/publishable key. Не используй `service_role`/secret key.
5. Для тестирования открой **Authentication → URL Configuration** и настрой Site URL на опубликованный адрес сайта. В Email Auth можешь временно выключить подтверждение email для тестов, но для публичного сервиса лучше оставить подтверждение включённым.

### 2. Подключи frontend
Открой `app.js` в редакторе кода на телефоне и замени первые две строки:
```js
const SUPABASE_URL = "PASTE_YOUR_SUPABASE_PROJECT_URL";
const SUPABASE_ANON_KEY = "PASTE_YOUR_SUPABASE_ANON_KEY";
```
на свои Project URL и anon/publishable key. Это публичный клиентский ключ; безопасность обеспечивают политики RLS в SQL. Никому не отправляй пароль от Supabase.

### 3. Опубликуй сайт с телефона
Простой путь:
1. Создай аккаунт на https://github.com/ и новый репозиторий, например `glasschat`.
2. В репозитории нажми **Add file → Upload files**, загрузи все файлы из папки проекта. Убедись, что `index.html` лежит в корне.
3. В **Settings → Pages** выбери публикацию из ветки `main`, папка `/ (root)`, нажми Save.
4. Адрес будет примерно `https://ТВОЙ-АККАУНТ.github.io/glasschat/`. Впиши именно его в Supabase **Authentication → URL Configuration** как Site URL и добавь в Redirect URLs.
5. Открой опубликованный сайт на телефоне. Если регистрации/входа не работает, проверь URL/key и настройки подтверждения email.

Примечание: GitHub Pages публикует статический frontend по HTTPS; Supabase предоставляет сервер, базу и realtime. Для PWA лучше использовать домен/хостинг с корректной поддержкой service worker и проверь запуск по HTTPS.

## Проверка
1. Создай два тестовых аккаунта с разными email.
2. Войди первым аккаунтом и найди email второго.
3. Нажми «Написать», отправь сообщение.
4. Выйди и войди вторым аккаунтом; чат должен появиться, сообщения сохраняются.
5. Открой второй аккаунт на другом устройстве/браузере для проверки realtime.

## Файлы
- `index.html` — интерфейс.
- `style.css` — Liquid Glass tinted оформление и мобильная адаптация.
- `app.js` — auth, поиск, создание чатов, отправка/получение сообщений.
- `supabase.sql` — схема БД, функции и RLS.
- `manifest.webmanifest`, `sw.js` — PWA.
